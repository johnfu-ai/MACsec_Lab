## 4.6 参数集逐个参考

MKPDU 的 body 是一串参数集的顺序拼接。这一节按类型号逐个给出字段表——它是全书查阅频率最高的一节，建议配合 `captures/decoded/` 的逐字段报告对照使用。

### 4.6.1 Basic Parameter Set（必备，永远是第一个）

octet 1 是 **MKA 版本**（不是类型号）：**2** = 802.1X-2010（绝大多数部署），**3** = 802.1X-2020（XPN 的 SSCI 字节属于这个版本；`mka-xpn.pcap` 用 3）。

| 字段 | 位置 | 含义 |
|---|---|---|
| Version | 1 | 2 或 3 |
| KS Priority | 2 | 越小越优先 |
| KS/Desired/Cap + Len | 3-4 | bit7=Key Server，bit6=MACsec Desired，bit5-4=Capability（0 不支持 / 1 仅完整性 / 2 完整性+机密性 offset 0 / 3 再加 co 30/50），低 12 位 body 长度 |
| SCI | 5-12 | 发送方安全通道标识 |
| Actor MI | 13-24 | 发送方成员标识 |
| Actor MN | 25-28 | 报文序号 |
| Algorithm Agility | 29-32 | `00-80-C2-01` = AES-CMAC 族 |
| CKN | 33.. | CA 名字（长度可变） |

### 4.6.2 Live Peer List（1）/ Potential Peer List（2）

| 字段 | 位置 | 含义 |
|---|---|---|
| Param type | 1 | 1 = Live，2 = Potential |
| **KS SSCI** | 2 | 发送方自己 SC 的 SSCI **低字节**；非 XPN 一律 0，XPN 时非 0——这是识别 XPN 会话最快的方式（[`mka-xpn.pcap`](../captures/mka-xpn.pcap) 帧 2+） |
| Body length | 3-4 | 16 × 成员数 |
| 对端条目 | 每条 16 B | MI(12) ‖ 已确认的对端 MN(4)；KS 的 Live List 带 2 条即 2 成员 CA（[`mka-multi-peer.pcap`](../captures/mka-multi-peer.pcap) 帧 4） |

### 4.6.3 MACsec SAK Use（3）——每条 MKPDU 都可能带

声明"我在用/能收哪些 SA"。40 字节 body（不支持 MACsec 的成员 body 为空）：

| 字段 | 位置 | 含义 |
|---|---|---|
| Latest AN/tx/rx | 2 高位 | 新 SA 的关联号 + 我用它发/我能用它收 |
| Old AN/tx/rx | 2 低位 | 旧 SA（换钥过渡期），`old KN=0` 表示无 |
| plain_tx / plain_rx / **delay_protect** | 3 高位 | 是否允许明文收发；delay protect 开关 |
| Latest KS MI + KN | 4-20 | KI：哪把 SAK（KS 的 MI ‖ KN） |
| Latest lowest PN (LLPN) | 20-24 | 我仍可接受的最低 PN（delay protect 的地板） |
| Old KS MI + KN + OLPN | 24-40 | 旧钥同构，换钥排空用 |

换钥故事的三段式全在这张表里：[`mka-rekey.pcap`](../captures/mka-rekey.pcap) 帧 5（latest=新 tx，old=旧 tx+rx）→ 帧 6（双 tx+rx）→ 帧 7（old 只 rx 排空）→ 帧 9（old KN=0 退役）。[`mka-delay-protect.pcap`](../captures/mka-delay-protect.pcap) 帧 10 演示 LLPN=3 发布。

### 4.6.4 Distributed SAK（4）——只在换钥时出现

| 字段 | 位置 | 含义 |
|---|---|---|
| AN + offset code | 2 | 高 2 位 = AN；接着 2 位 = confidentiality offset（0→0，1→30，2→50 字节明文前缀） |
| Key Number | 5-8 | KN |
| Cipher Suite ID | 9-16（可选） | 8 字节套件 ID；**默认套件 GCM-AES-128 省略整个字段**（body 28），其余套件带（128 位 SAK body 36 / 256 位 52）——见[第七章](../07_cipher_suites/7.1_negotiation.md) |
| AES-KW(SAK) | 其后 | AES-KeyWrap(KEK, SAK)，比 SAK 长 8 字节（wrap IV） |

同 SAK 只分发**一次**（组密钥）：[`mka-multi-peer.pcap`](../captures/mka-multi-peer.pcap) 全程仅一条 Distributed SAK，全体成员共用。
