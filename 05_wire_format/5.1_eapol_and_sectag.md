## 5.1 EAPOL 头与 SecTAG 比特布局

在逐帧解析之前，先把两条平面的"信封"看清：控制面的 MKA 跑在 EAPOL 上，数据面的 MACsec 用 SecTAG 替换掉原帧的头部信息。这两个头部的每一个比特，都会在后面 13 帧里反复出现。

### 5.1.1 EAPOL 头：MKA 的信封

MKA 跑在 **EAPOL** 上，目的 MAC 是 PAE 组地址 `01:80:c2:00:00:03`，EtherType `0x888E`。

```
[ DA ][ SA ][ 0x888E ][ Version=3 ][ Type=5 ][ Length ][ MKPDU ][ ICV 16 ]
```

| 字段 | 本实验室 |
|---|---|
| Version | 3（802.1X-2010） |
| **Packet Type** | **5 = EAPOL-MKA**（Table 11-3 编码 `0000 0101`） |
| Length | MKPDU 字节数（含 ICV） |

Type **6** 是 EAPOL-Announcement，不是 MKA。Wireshark 显示 `Type: MKA (5)`。

### 5.1.2 MACsec 帧在以太网上的位置

数据面上，SecY 用 **SAK** 保护用户帧。CAK / CKN / KEK / ICK 都不进入 GCM。SAK 从哪来见[第二章](../02_key_hierarchy/README.md)；控制面（谁生成 SAK、怎么发给对端）见 [5.2 节](5.2_mka_byte_by_byte.md)与 [5.3 节](5.3_control_plane_frames.md)。

```
[ DA 6 ][ SA 6 ][ 0x88E5 ][ TCI/AN 1 | SL 1 | PN 4 | SCI 0或8 ][ Secure Data ][ ICV 16 ]
```

`0x88E5` **算在 SecTAG 里**（802.1AE Clause 9）。GCM 的 AAD 从 DA 开始，包含这两个字节。

### 5.1.3 TCI / AN：SecTAG 的第 1 字节

bit 8 是 MSB：

| 位 | 掩码 | 含义 |
|---|---|---|
| V | `0x80` | 版本，**当前必须为 0** |
| ES | `0x40` | End Station。源 MAC 即 SCI 的 MAC 时置 1；ES=1 时不要再置 SC |
| SC | `0x20` | SecTAG **显式携带 8 字节 SCI** |
| SCB | `0x10` | EPON Single Copy Broadcast |
| E | `0x08` | User Data 是否加密 |
| C | `0x04` | 算法是否改写了 User Data |
| AN | `0x03` | SA 编号 0–3，换 SAK 时递增 |

E/C 组合：

| E | C | 抓包含义 |
|---|---|---|
| 1 | 1 | 机密性 + 完整性（实验室 `macsec-lab-encrypted.pcap`） |
| 0 | 0 | 只完整性，载荷明文（`macsec-lab-integrity-only.pcap`） |
| 0 | 1 | 只完整性但算法改写了载荷（少见） |
| 1 | 0 | **非法** |

实验室点对点两种编码都有：

- **SC=1**：SCI 在 SecTAG 里（多成员 CA 的常规做法；点对点也可以）
- **ES=1, SC=0**：SCI 不出现，接收方用 `SA ‖ 00-01` 还原（点对点常见）

IV **永远**用完整 8 字节 SCI，即使线上没带。

### 5.1.4 SL 与 PN

- **SL**（低 6 bit）：Secure Data 长度 &lt; 48 时填该长度，否则 0。实验室 ICMP User Data = 40 字节，所以 SL=40。
- **PN**：32 bit 大端，抗重放。同一把 SAK 上 PN 不得重复；耗尽前必须换 SAK（否则 GCM nonce 复用）。
