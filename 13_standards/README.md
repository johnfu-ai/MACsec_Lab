# 第十三章 标准演进

MACsec 不是一份静止的文档：从 2006 年的 802.1AE 基础版到今天的多个修正案，数据面与控制面各自经历了二十年的演进。读协议时"哪一年加入了什么"不只是历史 trivia——它解释了为什么 XPN 的 PN 是 64 位、为什么默认套件没有套件 ID 字段、为什么 MKA 直到 2010 年才存在。本章把这条时间线摊开，并给出条款级对照表，方便阅读时按图索骥。

本章主要内容包括：

- **13.1 802.1AE 演进：数据面**：从 2006 基础版到 2023 的 MAC Privacy Protection，每个版本带来了什么
- **13.2 802.1X 演进：控制面**：EAPOL 与 MKA 的历史，以及 PSK/EAP 两条故事线的历史背景
- **13.3 周边生态与条款级对照**：802.1Q/802.1AR 等相关标准，以及"学到哪个主题查哪条条款"的对照表

通过本章的学习，读者将能够把书中任何主题定位到具体标准与条款，理解各特性引入的年代与动机，并在需要时回到标准原文求证。
